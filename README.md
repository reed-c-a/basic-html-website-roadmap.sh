# basic-html-website-roadmap.sh

GitHub repository containing a solution to roadmap.sh's "Basic HTML Website Project."

## General Information

This project was undertaken in order to obtain some understanding of HTML, its content, and how to apply it
to make a functional website. It was made roughly according to roadmap.sh's specifications and for the purpose
of advancing in the website's Frontend path.

## Technology Stack

Basic structure, metadata: HTML 5
Decoration (e.g margins, padding): CSS
